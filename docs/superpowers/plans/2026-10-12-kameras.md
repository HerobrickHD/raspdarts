# Kamerabilder auf der Boards-Seite – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auf `play.autodarts.com/boards` bekommt die Karte des Raspdarts-Boards einen Kamera-Knopf hinter „Kalibrieren“, der ein Fenster mit den Kamerabildern (1×/s erneuert) öffnet – ohne Autodarts zu stören.

**Architecture:** Der Raspdarts-Server holt die Bilder bei Autodarts (`127.0.0.1:3180/api/img/cams/<n>`) und bremst zentral: höchstens ein Abruf pro Sekunde und Kamera, im Standby keiner. Die Extension liest den Board-Zustand aus dem Abzeichen der Karte (keine Abfrage), holt `GET /api/cams` einmal pro Besuch von `/boards` und im offenen Fenster Runde für Runde `GET /api/cams/<n>` über den Background-Teil.

**Tech Stack:** Server: Node ≥ 20, TypeScript (strict, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`), Fastify 5, Vitest. Extension: Manifest V3 (Chrome + Firefox), Content-Scripts als einfache Skripte mit `globalThis`-Modulen, Vitest ohne DOM.

**Spec:** `docs/superpowers/specs/2026-10-12-kameras-design.md`

## Global Constraints

- Raspdarts öffnet die Kameras nie selbst; Bilder nur über `GET <AUTODARTS_URL>/api/img/cams/<n>`.
- Höchstens 1 Bildabruf pro Sekunde und Kamera bei Autodarts, egal wie viele Browser zuschauen; während ein Abruf läuft, kein zweiter.
- Bei `running:false` kein Bildabruf bei Autodarts (`409 {"error":"board-stopped"}`).
- Die Autodarts-Config enthält `auth.api_key` – nie weitergeben, auch nicht in Fehlermeldungen.
- Zeitlimit für jeden Abruf bei Autodarts: 2 s. Zwischenspeicher: Bild 1 s je Kamera, `/api/state` 1 s, Config 30 s.
- `AUTODARTS_URL`, Vorgabe `http://127.0.0.1:3180`. `status.ts` bleibt unverändert.
- Alle `/api`-Pfade verlangen `X-Raspdarts: 1` und einen erlaubten Host (besteht schon in `http.ts`).
- Knopf nur auf `/boards`, nur auf der Karte mit `a[href="/boards/<board_id>/follow"]`, klickbar nur bei Abzeichen genau `Running`.
- Keine neue Berechtigung in den Manifesten. `content.js` bleibt unverändert.
- Texte Deutsch und Englisch; Code-Kommentare deutsch ohne Umlaute (wie im Bestand), Texte für Menschen mit Umlauten.
- Python ist auf diesem Rechner nicht installiert – Hilfsskripte in Node oder Bash.

```ts
/**
 * Kamerabilder von Autodarts fuer die Boards-Seite der Extension.
 *
 * Raspdarts oeffnet die Kameras nie selbst - Autodarts belegt sie exklusiv.
 * Stattdessen liefert Autodarts das zuletzt aufgenommene Bild ueber seine
 * lokale Schnittstelle. Damit Autodarts davon nichts merkt, fragt dieser
 * Baustein hoechstens einmal pro Sekunde und Kamera nach, egal wie viele
 * Browser zuschauen, und im Standby gar nicht (dann liefert Autodarts ohnehin
 * nur schwarze Bilder). Siehe docs/superpowers/specs/2026-10-12-kameras-design.md.
 *
 * Die Config von Autodarts enthaelt den API-Key des Boards; hier werden nur
 * Board-ID und Kameraanzahl herausgenommen, der Rest verlaesst diese Datei nie.
 */
import { parseBoardState } from "./status.js";

export interface AutodartsHttp {
  /** GET mit Zeitlimit; wirft bei Netzfehler, Zeitueberschreitung oder Fehlerstatus. */
  json(path: string, timeoutMs: number): Promise<unknown>;
  bytes(path: string, timeoutMs: number): Promise<Buffer>;
}

export interface CamsDeps {
  http: AutodartsHttp;
  now: () => number;
}

export interface CamsInfo {
  board_id: string | null;
  cams: number;
  /** Bildabrufe bei Autodarts seit dem Start (fuer die Abnahme-Messung). */
  fetched: number;
}

export type CamFailure = "not-found" | "board-stopped" | "unavailable";
export type CamImage = { ok: true; jpeg: Buffer } | { ok: false; reason: CamFailure };

export interface Cams {
  /** Wirft, wenn Autodarts nicht antwortet. */
  info(): Promise<CamsInfo>;
  image(n: number): Promise<CamImage>;
}

const TIMEOUT_MS = 2000;
const IMAGE_TTL_MS = 1000;
const STATE_TTL_MS = 1000;
const CONFIG_TTL_MS = 30_000;

/** Nimmt aus der Autodarts-Config nur Board-ID und Anzahl belegter Kamera-Plaetze. */
export function parseCamsConfig(body: unknown): { board_id: string | null; cams: number } | null {
  if (typeof body !== "object" || body === null) return null;
  const { auth, cam } = body as Record<string, unknown>;
  const list = (cam as Record<string, unknown> | null | undefined)?.["cams"];
  if (!Array.isArray(list)) return null;
  const id = (auth as Record<string, unknown> | null | undefined)?.["board_id"];
  return {
    board_id: typeof id === "string" && id.length > 0 ? id : null,
    cams: list.filter((entry) => typeof entry === "string" && entry.length > 0).length,
  };
}

/**
 * Haelt das Ergebnis von `load` fuer `ttlMs` ab dem Ende des Abrufs. Solange
 * ein Abruf laeuft, bekommen alle Aufrufer denselben - auch wenn er laenger
 * als `ttlMs` dauert. Ein Fehler wird nicht gemerkt.
 */
export function cached<T>(ttlMs: number, now: () => number, load: () => Promise<T>): () => Promise<T> {
  let entry: { promise: Promise<T>; settledAt: number | null } | null = null;
  return () => {
    if (entry && (entry.settledAt === null || now() - entry.settledAt < ttlMs)) return entry.promise;
    const current: { promise: Promise<T>; settledAt: number | null } = { promise: load(), settledAt: null };
    entry = current;
    current.promise.then(
      () => { current.settledAt = now(); },
      () => { if (entry === current) entry = null; },
    );
    return current.promise;
  };
}

export function createCams(deps: CamsDeps): Cams {
  let fetched = 0;

  const config = cached(CONFIG_TTL_MS, deps.now, async () => {
    const parsed = parseCamsConfig(await deps.http.json("/api/config", TIMEOUT_MS));
    if (!parsed) throw new Error("Unerwartete Config");
    return parsed;
  });

  // null = keine brauchbare Antwort; auch das gilt eine Sekunde.
  const running = cached(STATE_TTL_MS, deps.now, async (): Promise<boolean | null> => {
    try {
      return parseBoardState(await deps.http.json("/api/state", TIMEOUT_MS))?.running ?? null;
    } catch {
      return null;
    }
  });

  const images = new Map<number, () => Promise<CamImage>>();
  function imageOf(n: number): Promise<CamImage> {
    let load = images.get(n);
    if (!load) {
      load = cached(IMAGE_TTL_MS, deps.now, async (): Promise<CamImage> => {
        fetched += 1;
        try {
          return { ok: true, jpeg: await deps.http.bytes(`/api/img/cams/${n}`, TIMEOUT_MS) };
        } catch {
          return { ok: false, reason: "unavailable" };
        }
      });
      images.set(n, load);
    }
    return load();
  }

  return {
    async info() {
      const { board_id, cams } = await config();
      return { board_id, cams, fetched };
    },
    async image(n) {
      let cams: number;
      try {
        ({ cams } = await config());
      } catch {
        return { ok: false, reason: "unavailable" };
      }
      if (!Number.isInteger(n) || n < 0 || n >= cams) return { ok: false, reason: "not-found" };
      const state = await running();
      if (state === null) return { ok: false, reason: "unavailable" };
      if (!state) return { ok: false, reason: "board-stopped" };
      return imageOf(n);
    },
  };
}

export function autodartsHttp(baseUrl: string): AutodartsHttp {
  async function get(path: string, timeoutMs: number): Promise<Response> {
    const response = await fetch(`${baseUrl}${path}`, { signal: AbortSignal.timeout(timeoutMs) });

'use strict';

// Reine Logik fuer den Kamera-Knopf auf play.autodarts.com/boards und das
// Kamerafenster. Ohne DOM, damit sie sich ohne Browser testen laesst.
// Siehe docs/superpowers/specs/2026-10-12-kameras-design.md.
(function (root) {
  // Pause zwischen zwei Abrufrunden; der Pi bremst zusaetzlich selbst.
  const ROUND_PAUSE_MS = 1000;

  function isBoardsPage(pathname) {
    return pathname === '/boards' || pathname === '/boards/';
  }

  // Autodarts schreibt den Zustand auch bei deutscher Oberflaeche englisch.
  function buttonState(badgeText, t) {
    const enabled = (badgeText ?? '').trim() === 'Running';
    return { enabled, title: enabled ? t.camsButton : t.camsButtonStopped };
  }

  const label = (index, t) => `${t.camsCamera} ${index + 1}`;

  function emptyTiles(count, t) {
    return Array.from({ length: count }, (_, i) => ({ label: label(i, t), src: null, stale: false, note: null }));
  }

  // results: Antworten des Background-Teils je Kamera ({ ok, status, dataUrl }).
  // previous: Kacheln der vorigen Runde; fehlt ein Bild, bleibt das letzte
  // abgedunkelt stehen.
  function windowView(results, previous, t) {
    if (results.some((result) => result?.status === 409)) {
      return { message: t.camsBoardStopped, tiles: previous };
    }
    const tiles = results.map((result, i) => {
      if (result?.ok && typeof result.dataUrl === 'string') {
        return { label: label(i, t), src: result.dataUrl, stale: false, note: null };
      }
      return { label: label(i, t), src: previous[i]?.src ?? null, stale: true, note: t.camsNoImage };
    });
    return { message: null, tiles };
  }

  root.raspdartsCamsView = { ROUND_PAUSE_MS, buttonState, emptyTiles, isBoardsPage, windowView };
})(globalThis);

// Kamerabild fuer das Kamerafenster auf play.autodarts.com/boards. Kommt als
// Daten-URL zurueck, weil die HTTPS-Seite nichts direkt vom Pi laden darf.
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  if (msg.type !== 'image') return false;
  fetch(`${BASE_URL}/api/cams/${Number(msg.cam)}`, { headers: CLIENT_HEADERS, cache: 'no-store' })
    .then(async (res) => {
      if (!res.ok) {
        sendResponse({ ok: false, status: res.status });
        return;
      }
      const bytes = new Uint8Array(await res.arrayBuffer());
      sendResponse({ ok: true, status: res.status, dataUrl: `data:image/jpeg;base64,${toBase64(bytes)}` });
    })
    .catch(() => sendResponse({ ok: false, status: 0, error: 'Unreachable' }));
  return true; // async response
});

// btoa braucht eine Zeichenkette; in Stuecken, damit der Aufruf-Stack nicht ueberlaeuft.
function toBase64(bytes) {
  let binary = '';
  for (let i = 0; i < bytes.length; i += 0x8000) {
    binary += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  }
  return btoa(binary);
}

    img { display: block; width: 100%; height: 100%; object-fit: contain; }
    .stale img { opacity: 0.35; }
    .note { position: absolute; inset: 0; display: flex; align-items: center; justify-content: center; font-weight: 700; }
    .label { margin-top: 6px; font-size: 13px; color: var(--color-black-20, #cacfd9); }
    [hidden] { display: none !important; }
  `;

  let texts = null;
  let info = null;           // { board_id, cams } vom Pi
  let infoRequested = false; // je Besuch von /boards einmal
  let session = null;        // { open, tiles, message } solange das Fenster offen ist
  let host = null;

  function t() {
    if (!texts) texts = getTexts(detectLanguage(document.querySelector('header nav')?.getAttribute('aria-label')));
    return texts;
  }

  function sendToBackground(msg) {
    return new Promise((resolve) => chrome.runtime.sendMessage(msg, resolve));
  }

  async function loadInfo() {
    const result = await sendToBackground({ type: 'fetch', url: '/api/cams' });
    const data = result?.ok ? result.data : null;
    if (typeof data?.board_id === 'string' && Number.isInteger(data.cams)) {
      info = { board_id: data.board_id, cams: data.cams };
    }
  }

  // --- Knopf auf der Karte ------------------------------------------------------

  // Aufbau der Karte (Stand 12.10.2026):
  //   Karte > Kopfzeile (Name, Einstellungen, Zustands-Abzeichen) … Knopfzeile
  //   Knopfzeile > linke Gruppe (Starten/Stoppen, Kalibrieren, Board Manager)
  //              | rechte Gruppe (ID kopieren, "Board folgen"-Link, …)
  function locateCard(boardId) {
    const follow = document.querySelector(`a[href="/boards/${CSS.escape(boardId)}/follow"]`);
    const row = follow?.parentElement?.parentElement;
    const card = row?.parentElement;
    const leftGroup = row?.firstElementChild;
    const head = card?.firstElementChild;
    if (!card || !leftGroup || !head || leftGroup === follow.parentElement) return null;
    return {
      leftGroup,
      badge: head.querySelector('.rounded-full'),
      name: head.querySelector('span')?.textContent.trim() || 'Board',
    };
  }

  // Der Knopf steckt in einem <span>, das den Hinweis traegt: Autodarts'
  // Klassen schalten bei deaktivierten Knoepfen die Maus ab, dann zeigte der
  // Knopf selbst keinen Hinweis.
  function ensureButton(parts) {
    let wrap = document.getElementById(BUTTON_ID);
    if (wrap && parts.leftGroup.contains(wrap)) return wrap;
    wrap?.remove();

    // Kalibrieren ist der zweite Knopf der Gruppe; erkannt an der Position, nicht am Text.
    const calibrate = parts.leftGroup.children[1];
    wrap = document.createElement('span');
    wrap.id = BUTTON_ID;
    wrap.style.display = 'inline-flex';
    const btn = document.createElement('button');
    btn.type = 'button';
    btn.className = (calibrate ?? parts.leftGroup.lastElementChild)?.className ?? '';
    btn.innerHTML = CAMERA_ICON;
    btn.addEventListener('click', openWindow);
    wrap.append(btn);
    if (calibrate) calibrate.after(wrap);
    else parts.leftGroup.append(wrap);
    return wrap;
  }

  function updateButton(wrap, badgeText) {
    const state = buttonState(badgeText, t());
    const btn = wrap.firstElementChild;
    if (btn.disabled !== !state.enabled) btn.disabled = !state.enabled;
    if (wrap.title !== state.title) {
      wrap.title = state.title;
      btn.setAttribute('aria-label', state.title);
    }
  }

  function refreshButton() {
    if (!info || !isBoardsPage(location.pathname)) return;
    const parts = locateCard(info.board_id);
    if (!parts) return;
    updateButton(ensureButton(parts), parts.badge?.textContent);
  }

  // --- Fenster -------------------------------------------------------------------

  function buildWindow(name) {
    const el = document.createElement('div');
    el.id = HOST_ID;
    const shadow = el.attachShadow({ mode: 'open' });
    shadow.innerHTML = `<style>${STYLE}</style>
      <div class="backdrop">
        <div class="window" role="dialog" aria-modal="true">
          <div class="head"><h2></h2><button type="button" class="close">✕</button></div>
          <p class="message" hidden></p>
          <div class="grid"></div>
        </div>
      </div>`;
    shadow.querySelector('h2').textContent = `${t().camsTitle} – ${name}`;
    const close = shadow.querySelector('.close');
    close.title = t().close;
    close.setAttribute('aria-label', t().close);
    close.addEventListener('click', closeWindow);
    shadow.querySelector('.backdrop').addEventListener('click', (event) => {
      if (event.target === event.currentTarget) closeWindow();
    });
    return el;
  }

  function tileElement() {
    const figure = document.createElement('figure');
    figure.className = 'tile';
    figure.innerHTML = '<div class="frame"><img alt=""><span class="note" hidden></span></div>'
      + '<figcaption class="label"></figcaption>';
    return figure;
  }

  function render() {
    if (!host || !session) return;
    const shadow = host.shadowRoot;
    const message = session.message ?? (session.tiles.length === 0 ? t().camsNoImage : null);
    const paragraph = shadow.querySelector('.message');
    paragraph.hidden = !message;
    paragraph.textContent = message ?? '';

    const grid = shadow.querySelector('.grid');
    grid.hidden = Boolean(session.message);
    // Kacheln nur bei geaenderter Anzahl neu anlegen, sonst flackert es.
    while (grid.children.length > session.tiles.length) grid.lastElementChild.remove();
    while (grid.children.length < session.tiles.length) grid.append(tileElement());
    session.tiles.forEach((tile, i) => {
      const el = grid.children[i];
      el.querySelector('.label').textContent = tile.label;
      el.classList.toggle('stale', tile.stale);
      const img = el.querySelector('img');
      img.hidden = !tile.src;
      if (tile.src && img.getAttribute('src') !== tile.src) img.src = tile.src;
      const note = el.querySelector('.note');
      note.hidden = !tile.note;
      note.textContent = tile.note ?? '';
    });
  }

  function onKey(event) {
    if (event.key !== 'Escape') return;
    event.stopPropagation();
    closeWindow();
  }

  function openWindow() {
    if (session || !info) return;
    const current = { open: true, tiles: emptyTiles(info.cams, t()), message: null };
    session = current;
    host = buildWindow(locateCard(info.board_id)?.name ?? 'Board');
    document.body.append(host);
    document.addEventListener('keydown', onKey, true);
    render();
    // Kameraanzahl auffrischen (Kamera ab- oder angesteckt), dann Runden starten.
    loadInfo().finally(() => {
      if (!current.open) return;
      if (info.cams !== current.tiles.length) current.tiles = emptyTiles(info.cams, t());
      render();
      runRounds(current);
    });
  }

  function closeWindow() {
    if (!session) return;
    session.open = false;
    session = null;
    host?.remove();
    host = null;
    document.removeEventListener('keydown', onKey, true);
  }

  // Eine Runde holt alle Kameras nacheinander; die naechste beginnt erst eine
  // Sekunde nach dem Ende der vorigen. So stauen sich bei langsamem WLAN keine
  // Anfragen. Im versteckten Tab wird nichts geholt.
  async function runRounds(current) {
    while (current.open) {
      if (!document.hidden) {
        const results = [];
        for (let cam = 0; cam < current.tiles.length; cam += 1) {
          const result = await sendToBackground({ type: 'image', cam });
          if (!current.open) return;
          results.push(result);
          if (result?.status === 409) break; // Board steht: die anderen gar nicht erst fragen
        }
        const view = windowView(results, current.tiles, t());
        current.tiles = view.tiles;
        current.message = view.message;
        render();
      }
      await new Promise((resolve) => setTimeout(resolve, ROUND_PAUSE_MS));
    }
  }

  // --- Seitenwechsel -------------------------------------------------------------

  function onDomChange() {
    if (!isBoardsPage(location.pathname)) {
      infoRequested = false;
      closeWindow();
      return;
    }
    if (!infoRequested) {
      infoRequested = true;
      loadInfo().then(refreshButton);
      return;
    }
    refreshButton();
  }

  onDomChange();
  // Autodarts wechselt Seiten ohne Neuladen und baut Karten neu auf; das
  // Abzeichen aendert dabei seinen Text.
  new MutationObserver(onDomChange).observe(document.body, { childList: true, subtree: true, characterData: true });
})();
```

// CORS) und liefert die gebauten Extension-Dateien unter /dist/ aus.
import http from 'node:http';
import { readFile } from 'node:fs/promises';
import { join } from 'node:path';

const TARGET = 'http://localhost:8743';
const DIST = process.argv[2];

http.createServer(async (req, res) => {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Headers', '*');
  if (req.method === 'OPTIONS') return res.end();
  try {
    if (req.url.startsWith('/dist/')) {
      res.setHeader('Content-Type', 'text/javascript');
      return res.end(await readFile(join(DIST, req.url.slice(6))));
    }
    const upstream = await fetch(TARGET + req.url, { headers: { 'X-Raspdarts': '1' } });
    res.writeHead(upstream.status, { 'Content-Type': upstream.headers.get('content-type') ?? 'application/octet-stream' });
    res.end(Buffer.from(await upstream.arrayBuffer()));
  } catch (error) {
    res.writeHead(502);
    res.end(String(error));
  }
}).listen(8744, () => console.log('Proxy auf http://localhost:8744'));

```bash
#!/usr/bin/env bash
# Usage: messung.sh <name>   – 60 s Autodarts-Werte mitlesen, Zuwachs von "fetched" ausgeben
H='X-Raspdarts: 1'; P=http://raspdarts.local:8743; A=http://raspdarts.local:3180
fetched() { curl -s -H "$H" "$P/api/cams" | sed -E 's/.*"fetched":([0-9]+).*/\1/'; }
f0=$(fetched)
for i in $(seq 60); do curl -s -m 2 "$A/api/state/stats"; echo; sleep 1; done > "$1.ndjson"
f1=$(fetched)
node -e '
  const rows = require("fs").readFileSync(process.argv[1], "utf8").trim().split("\n").map((l) => JSON.parse(l));
  const avg = (k) => (rows.reduce((s, r) => s + r[k], 0) / rows.length).toFixed(1);
  const min = (k) => Math.min(...rows.map((r) => r[k])).toFixed(1);
  console.log(`${process.argv[2]}: cpu Ø ${avg("cpuPercent")} %, fps Ø ${avg("fps")} (min ${min("fps")}), Bildabrufe ${process.argv[3]}`);
' "$1.ndjson" "$1" "$((f1 - f0))"
```

Drei Durchgänge, jeweils 60 s:
1. `bash messung.sh ohne` – kein Fenster offen.
2. `bash messung.sh ein-fenster` – Arnold hat auf `/boards` das Kamerafenster offen.
3. `bash messung.sh zwei-fenster` – zusätzlich ein zweites Fenster (zweiter Tab oder zweiter Rechner) offen.

Bestanden, wenn:
- fps Ø in allen drei Durchgängen gleich (±1) und min fps nicht unter dem Wert von „ohne“ minus 1,
- Bildabrufe bei „ohne“ = 0, bei „ein-fenster“ und „zwei-fenster“ je ≤ 183 (60 s × 3 Kameras + 3), und „zwei-fenster“ nicht nennenswert mehr als „ein-fenster“.
