# Viewer (Grundlage Projektion) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aus dem Beamer-Scoreboard wird der Viewer: schwarzer Grund, eigene gezeichnete Scheibe (Nur Licht / Gezeichnet / Linien), Spielerkarten und Aufnahmeleiste im Autodarts-Stil, Layout je Anzeige mit Live-Editor zum Ausrichten der Scheibe auf die echte Scheibe.

**Architecture:** Der Pi übersetzt Autodarts' Match-Stand in einen `ViewerState` (nur `server/src/viewer/game-state.ts` kennt das Autodarts-Format) und verteilt ihn sowie das Layout der jeweiligen Anzeige über `/ws?display=<name>`. Der Viewer in `server/public/` ist einfaches HTML/CSS/SVG mit ES-Modulen ohne Build-Schritt; reine Funktionen (Geometrie, Beschriftung) sind mit Vitest getestet, das Zeichnen wird von Hand gegen die Referenzbilder geprüft.

**Tech Stack:** Node ≥ 20, TypeScript 5, Fastify 5, @fastify/websocket 11, @fastify/static 10, Vitest 2, plain JavaScript (ES-Module) und SVG im Browser.

**Spec:** `docs/superpowers/specs/2026-10-08-viewer-design.md`

## Global Constraints

- Arbeitsverzeichnis für alle `npm`-Befehle: `server/`. Tests: `npm test`, Typprüfung: `npm run typecheck` (prüft nur `src/`).
- Node ≥ 20 (auf dem Pi läuft 20.20.2). Keine neuen Laufzeit-Abhängigkeiten in `package.json`; Schriften sind Dateien im Repo.
- Viewer ohne Build-Schritt: `server/public/` wird so ausgeliefert, wie es im Repo liegt. Browser-Code als ES-Module (`<script type="module">`), Dateien in `server/public/js/`.
- Spielregeln und Autodarts-Format nur in `server/src/viewer/game-state.ts`. Der Viewer rechnet keine Spielwerte.
- `/api/*` verlangt weiter `X-Raspdarts: 1` und einen erlaubten Host; `/ws` bleibt ohne Header lesbar.
- `GET /api/status` behält das Feld `beamer` (die Extension liest es; Extension bleibt unverändert).
- Standard-Anzeigename `standard`; erlaubte Namen `^[a-z0-9][a-z0-9-]{0,31}$` (Groß-/Kleinschreibung egal).
- Texte für Nutzer auf Deutsch mit Umlauten; Kommentare im Code auf Deutsch ohne Umlaute (wie im übrigen Code).
- Scheibenmaße (mm, Radien): Bull 6,35 · Single-Bull 15,9 · Triple 99–107 · Double 162–170 · Zahlenring bis 225. Zahlen im Uhrzeigersinn ab oben: 20, 1, 18, 4, 13, 6, 10, 15, 2, 17, 3, 19, 7, 16, 8, 11, 14, 9, 12, 5.
- Farben: Feld dunkel `#01040B`, hell Creme `#F3E5C8`, Rot `#E72946`, Grün `#009856`; letzter Dart `rgba(255, 220, 0, 0.65)`, Deckkraft 0,2 → 0,8 → 0,2 in 0,8 s.
- Layout-Grenzen: Position 0–100 %, `scale` 0,2–4, `diameter` 5–400 % (Double-Ring, % der Höhe), `rotation` −180–180°.
- Live-Verteilung: Editor sendet höchstens alle 100 ms; Pi schreibt die Datei höchstens alle 500 ms; `editing` fällt nach 60 s ohne Änderung auf `false`.
- Standard-Profilbild: `https://play.autodarts.com/assets/player-silhouette-X1nJGQO_.png`; Flaggen: `https://play.autodarts.com/flags/4x3/<land>.svg`.

## Review Focus

1. **Ungültiger Anzeigename in der Adresse** (`?display=Wohnzimmer TV`, `?display=../x`): Der Viewer funktioniert trotzdem und nutzt das Layout `standard` – kein Abbruch der Verbindung. → Test in Task 4.
2. **Unbrauchbarer Inhalt bei `PUT /api/layout/<name>`** (kein `layout`-Feld, Text statt Objekt, altes Format ohne `version`): Antwort 200 mit Standardlayout, kein 500, Datei bleibt brauchbar. → Test in Task 4.
3. **Viewer verbindet sich, während an einem anderen Gerät bearbeitet wird:** Er bekommt sofort `editing: true` und zeigt die Scheibe als Linien. → Test in Task 4.
4. **Daneben-Wurf als letzter Dart** (`number: 0`): Beschriftung `MISS`, keine Hervorhebung, kein Punkt ohne Koordinaten. → Tests in Task 2 (Hervorhebung) und Task 5 (Beschriftung).
5. **Spiel mit 3 Spielern bzw. Autodarts-Stand ohne `turns`/`stats`:** Übersetzung liefert alle Spieler mit Ersatzwerten, keine Ausnahme. → Test in Task 2.

```ts
/**
 * Uebersetzt die rohe Autodarts-Match-Nachricht in den ViewerState - den
 * einzigen Vertrag zwischen Dienst und Viewer.
 *
 * Diese Datei ist die einzige Stelle, die das Drahtformat von Autodarts kennt.
 * Spielregeln (Rest, Bust, Checkout-Weg, Sieger) entscheidet Autodarts; hier
 * wird nur uebersetzt, nie gerechnet. Felder geprueft am Mitschnitt vom
 * 8. Oktober 2026 (docs/referenz/autodarts-spielansicht/).
 */

/** Ein Feld der Scheibe. multiplier 0 / number 0 = daneben. */
export interface Field {
  multiplier: 0 | 1 | 2 | 3;
  number: number;
  /** Nur bei Single: innerer oder aeusserer Teil, sonst null. */
  ring: "inner" | "outer" | null;
}

export type Mode = "Straight" | "Double" | "Master";

export interface MatchInfo {
  baseScore: number;
  legsToWin: number;
  setsToWin: number | null;
  inMode: Mode;
  outMode: Mode;
}

export interface PlayerView {
  name: string;
  avatarUrl: string | null;
  country: string | null;
  score: number;
  legs: number;
  sets: number;
  average: { leg: number; match: number };
  dartsThrown: number;
  isActive: boolean;
  isWinner: boolean;
  /** Der aktive Spieler hat in dieser Aufnahme ueberworfen. */
  busted: boolean;
  checkout: Field[] | null;
}

export interface TurnDart {
  field: Field;
  /** Autodarts-Koordinaten: 1 = Aussenkante Double-Ring, y nach oben. */
  coords: { x: number; y: number } | null;
}

export interface Highlight {
  field: Field;
  kind: "last-dart";
}

export type ViewerState =
  | { phase: "idle" }
  | { phase: "unsupported"; variant: string }
  | {
      phase: "playing";
      variant: "X01";
      match: MatchInfo;
      players: PlayerView[];
      turn: { darts: TurnDart[]; points: number; busted: boolean };
      highlights: Highlight[];
    };

export const IDLE: ViewerState = { phase: "idle" };
export const MISS: Field = { multiplier: 0, number: 0, ring: null };

type Json = Record<string, unknown>;

const isObject = (v: unknown): v is Json => typeof v === "object" && v !== null;
const asArray = (v: unknown): unknown[] => (Array.isArray(v) ? v : []);
const asObject = (v: unknown): Json => (isObject(v) ? v : {});
const asNumber = (v: unknown, fallback = 0): number =>
  typeof v === "number" && Number.isFinite(v) ? v : fallback;
const asText = (v: unknown): string | null => (typeof v === "string" && v.length > 0 ? v : null);

/** Frames kommen je nach Kanal entweder direkt oder in ein `data`-Feld verpackt. */
function unwrap(raw: unknown): unknown {
  if (isObject(raw) && "data" in raw && isObject(raw["data"])) return raw["data"];
  return raw;
}

/** Feld aus einem Autodarts-Segment ({ bed, multiplier, number }). */
export function toField(raw: unknown): Field {
  if (!isObject(raw)) return MISS;
  const number = asNumber(raw["number"]);
  const rawMultiplier = asNumber(raw["multiplier"]);
  const isNumber = (number >= 1 && number <= 20) || number === 25;
  if (!isNumber || (rawMultiplier !== 1 && rawMultiplier !== 2 && rawMultiplier !== 3)) return MISS;
  if (number === 25 && rawMultiplier === 3) return MISS;
  // TypeScript engt number nicht per Vergleich auf 1 | 2 | 3 ein.
  const multiplier = rawMultiplier as 1 | 2 | 3;

  const bed = raw["bed"];
  const ring =
    multiplier === 1 && number !== 25
      ? bed === "SingleInner"
        ? "inner"
        : bed === "SingleOuter"
          ? "outer"
          : null
      : null;
  return { multiplier, number, ring };
}

function toCoords(raw: unknown): { x: number; y: number } | null {
  if (!isObject(raw)) return null;
  const { x, y } = raw;
  if (typeof x !== "number" || typeof y !== "number") return null;
  if (!Number.isFinite(x) || !Number.isFinite(y)) return null;
  return { x, y };
}

const toMode = (v: unknown): Mode => (v === "Double" || v === "Master" ? v : "Straight");

/** Ein leerer Weg (Autodarts schickt [] nach dem Leg) ist kein Weg. */
function toCheckout(raw: unknown): Field[] | null {
  const guide = asArray(raw);
  return guide.length === 0 ? null : guide.map(toField);
}

export function toViewerState(raw: unknown): ViewerState {
  const state = unwrap(raw);
  if (!isObject(state)) return IDLE;

  const players = asArray(state["players"]);
  const gameScores = asArray(state["gameScores"]);
  if (players.length === 0 || gameScores.length === 0) return IDLE;

  const variant = asText(state["variant"]) ?? "X01";
  if (variant !== "X01") return { phase: "unsupported", variant };

  const activeIndex = asNumber(state["player"], -1);
  const winner = asNumber(state["winner"], -1);
  const turnBusted = state["turnBusted"] === true;
  const scores = asArray(state["scores"]);
  const stats = asArray(state["stats"]);
  const inner = asObject(state["state"]);
  const guides = inner["checkoutGuides"];

  const playerViews: PlayerView[] = players.map((entry, index) => {
    const player = asObject(entry);
    const legStats = asObject(asObject(stats[index])["legStats"]);
    const matchStats = asObject(asObject(stats[index])["matchStats"]);
    const score = asObject(scores[index]);
    const isActive = index === activeIndex;
    const guide = Array.isArray(guides)
      ? guides[index]
      : isActive
        ? inner["checkoutGuide"]
        : null;
    return {
      name: asText(player["name"]) ?? `Spieler ${index + 1}`,
      avatarUrl: asText(player["avatarUrl"]),
      country: asText(asObject(player["user"])["country"]),
      score: asNumber(gameScores[index]),
      legs: asNumber(score["legs"]),
      sets: asNumber(score["sets"]),
      average: { leg: asNumber(legStats["average"]), match: asNumber(matchStats["average"]) },
      dartsThrown: asNumber(legStats["dartsThrown"]),
      isActive,
      isWinner: winner >= 0 && index === winner,
      busted: isActive && turnBusted,
      checkout: toCheckout(guide),
    };
  });

  const turns = asArray(state["turns"]);
  const throws = asArray(asObject(turns[turns.length - 1])["throws"]);
  const darts: TurnDart[] = throws.map((thrown) => {
    const t = asObject(thrown);
    return { field: toField(t["segment"]), coords: toCoords(t["coords"]) };
  });
  const last = darts[darts.length - 1];

  const settings = asObject(state["settings"]);
  const sets = state["sets"];
  return {
    phase: "playing",
    variant: "X01",
    match: {
      baseScore: asNumber(settings["baseScore"]),
      legsToWin: asNumber(state["legs"], 1),
      setsToWin: typeof sets === "number" ? sets : null,
      inMode: toMode(settings["inMode"]),
      outMode: toMode(settings["outMode"]),
    },
    players: playerViews,
    turn: { darts, points: asNumber(state["turnScore"]), busted: turnBusted },
    highlights: last && last.field.multiplier !== 0 ? [{ field: last.field, kind: "last-dart" }] : [],
  };
}
```

```ts
/**
 * Das Layout einer Anzeige: wo die Scheibe und jeder Baustein sitzt und wie
 * gross er ist.
 *
 * Positionen sind Prozentwerte der Bildflaeche, Groessen haengen an der
 * Bildhoehe - keine Pixel. Ein eingerichtetes Layout passt dadurch auch nach
 * einem Aufloesungswechsel des Beamers noch.
 */

export const PLAYER_BLOCKS = [
  "spieler-1",
  "spieler-2",
  "spieler-3",
  "spieler-4",
  "spieler-5",
  "spieler-6",
] as const;
export const BLOCK_IDS = ["kopf", "aufnahme", ...PLAYER_BLOCKS] as const;
export type BlockId = (typeof BLOCK_IDS)[number];

export interface BlockLayout {
  /** Linke obere Ecke, Prozent der Breite. */
  x: number;
  /** Prozent der Hoehe. */
  y: number;
  /** Relativ zur Grundgroesse des Bausteins. */
  scale: number;
}

export interface BoardLayout {
  /** Mittelpunkt, Prozent der Breite. */
  cx: number;
  /** Mittelpunkt, Prozent der Hoehe. */
  cy: number;
  /** Durchmesser des Double-Rings (340 mm), Prozent der Hoehe. */
  diameter: number;
  /** Grad, im Uhrzeigersinn. */
  rotation: number;
}

export type BoardMode = "light" | "drawn";

export interface DisplayLayout {
  version: 2;
  boardMode: BoardMode;
  board: BoardLayout;
  blocks: Record<BlockId, BlockLayout>;
}

export const DEFAULT_LAYOUT: DisplayLayout = {
  version: 2,
  boardMode: "light",
  board: { cx: 50, cy: 51, diameter: 50, rotation: 0 },
  blocks: {
    kopf: { x: 2, y: 3, scale: 1 },
    aufnahme: { x: 32.5, y: 3.8, scale: 1 },
    "spieler-1": { x: 1.4, y: 32.7, scale: 1 },
    "spieler-2": { x: 71, y: 32.7, scale: 1 },
    "spieler-3": { x: 1.4, y: 68, scale: 0.45 },
    "spieler-4": { x: 85.5, y: 68, scale: 0.45 },
    "spieler-5": { x: 1.4, y: 84, scale: 0.45 },
    "spieler-6": { x: 85.5, y: 84, scale: 0.45 },
  },
};

const LIMITS = {
  position: [0, 100],
  scale: [0.2, 4],
  diameter: [5, 400],
  rotation: [-180, 180],
} as const;

const clamp = (value: number, [min, max]: readonly [number, number]): number =>
  Math.min(max, Math.max(min, value));

const isNumber = (v: unknown): v is number => typeof v === "number" && Number.isFinite(v);

/** Ein Wert der Scheibe: begrenzt, oder bei Unbrauchbarem der Standard. */
function boardValue(v: unknown, fallback: number, limits: readonly [number, number]): number {
  return isNumber(v) ? clamp(v, limits) : fallback;
}

function sanitizeBlock(stored: unknown, fallback: BlockLayout): BlockLayout {
  if (typeof stored !== "object" || stored === null) return { ...fallback };
  const { x, y, scale } = stored as Record<string, unknown>;
  if (!isNumber(x) || !isNumber(y) || !isNumber(scale)) return { ...fallback };
  return {
    x: clamp(x, LIMITS.position),
    y: clamp(y, LIMITS.position),
    scale: clamp(scale, LIMITS.scale),
  };
}

/**
 * Macht aus beliebigem gespeichertem Inhalt ein brauchbares Layout.
 *
 * Der Inhalt kommt aus dem Browser und aus einer von Hand editierbaren Datei -
 * deshalb wird nichts geglaubt. Ein Layout ohne version 2 (die alten
 * Beamer-Layouts) gilt als nicht vorhanden. Eine kaputte Datei darf den Viewer
 * nie unbedienbar machen.
 */
export function sanitizeLayout(stored: unknown): DisplayLayout {
  const fresh = structuredClone(DEFAULT_LAYOUT);
  if (typeof stored !== "object" || stored === null) return fresh;
  const source = stored as Record<string, unknown>;
  if (source["version"] !== 2) return fresh;

  const board = (typeof source["board"] === "object" && source["board"] !== null
    ? source["board"]
    : {}) as Record<string, unknown>;
  const blocks = (typeof source["blocks"] === "object" && source["blocks"] !== null
    ? source["blocks"]
    : {}) as Record<string, unknown>;

  const defaults = DEFAULT_LAYOUT.board;
  fresh.boardMode = source["boardMode"] === "drawn" ? "drawn" : "light";
  fresh.board = {
    cx: boardValue(board["cx"], defaults.cx, LIMITS.position),
    cy: boardValue(board["cy"], defaults.cy, LIMITS.position),
    diameter: boardValue(board["diameter"], defaults.diameter, LIMITS.diameter),
    rotation: boardValue(board["rotation"], defaults.rotation, LIMITS.rotation),
  };
  for (const id of BLOCK_IDS) {
    fresh.blocks[id] = sanitizeBlock(blocks[id], DEFAULT_LAYOUT.blocks[id]);
  }
  return fresh;
}
```

- [ ] **Step 5: `layout-store.ts` ersetzen**

```ts
/**
 * Speichert das eingerichtete Layout pro Anzeige als JSON-Datei.
 *
 * Bewusst beim Dienst und nicht im Browser: so ueberlebt ein muehsam auf die
 * Scheibe ausgerichtetes Layout das Leeren des Browser-Caches und eine
 * Neuinstallation, und alle Geraete mit demselben Anzeigenamen sehen dasselbe.
 *
 * Beim Ausrichten kommen bis zu zehn Aenderungen pro Sekunde. Die gelten sofort
 * (Zwischenspeicher), auf die SD-Karte geschrieben wird gebuendelt.
 */
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { sanitizeLayout, type DisplayLayout } from "./layout.js";

/**
 * Der Anzeigename kommt aus der URL (?display=beamer). Ohne Pruefung liesse
 * sich damit ueber "../" eine beliebige Datei im Dateisystem lesen oder
 * ueberschreiben - deshalb nur schlichte Namen.
 */
const VALID_NAME = /^[a-z0-9][a-z0-9-]{0,31}$/i;

export const DEFAULT_DISPLAY = "standard";

/** Name aus der Adresse, oder der Standard, wenn er nicht taugt. */
export function displayName(raw: unknown): string {
  return typeof raw === "string" && VALID_NAME.test(raw) ? raw : DEFAULT_DISPLAY;
}

export class LayoutStore {
  readonly #cache = new Map<string, DisplayLayout>();
  readonly #pending = new Set<string>();
  #timer: NodeJS.Timeout | null = null;
  #warned = false;

  constructor(
    private readonly dir: string,
    private readonly flushDelayMs = 500,
  ) {
    try {
      mkdirSync(dir, { recursive: true });
    } catch (error) {
      this.#warn(error as Error);
    }
  }

  read(display: string): DisplayLayout {
    const path = this.#pathFor(display);
    const cached = this.#cache.get(display);
    if (cached) return structuredClone(cached);
    let layout: DisplayLayout;
    try {
      layout = sanitizeLayout(JSON.parse(readFileSync(path, "utf8")));
    } catch {
      // Noch nicht vorhanden oder beschaedigt - der Standard ist immer brauchbar.
      layout = sanitizeLayout(null);
    }
    this.#cache.set(display, layout);
    return structuredClone(layout);
  }

  /** Prueft, uebernimmt sofort und liefert das tatsaechlich gueltige Layout. */
  write(display: string, layout: unknown): DisplayLayout {
    this.#pathFor(display);
    const sanitized = sanitizeLayout(layout);
    this.#cache.set(display, sanitized);
    this.#pending.add(display);
    this.#schedule();
    return structuredClone(sanitized);
  }

  /** Schreibt alle offenen Aenderungen sofort (beim Beenden, in Tests). */
  flush(): void {
    if (this.#timer) clearTimeout(this.#timer);
    this.#timer = null;
    for (const display of this.#pending) {
      const layout = this.#cache.get(display);
      if (!layout) continue;
      try {
        writeFileSync(this.#pathFor(display), `${JSON.stringify(layout, null, 2)}\n`);
      } catch (error) {
        this.#warn(error as Error);
      }
    }
    this.#pending.clear();
  }

  #schedule(): void {
    if (this.#timer) return;
    this.#timer = setTimeout(() => {
      this.#timer = null;
      this.flush();
    }, this.flushDelayMs);
    this.#timer.unref?.();
  }

  /** Einmal warnen; danach gilt das Layout bis zum Neustart nur im Speicher. */
  #warn(error: Error): void {
    if (this.#warned) return;
    this.#warned = true;
    console.warn(`Layout kann nicht gespeichert werden: ${error.message}`);
  }

  #pathFor(display: string): string {
    if (!VALID_NAME.test(display)) {
      throw new Error(
        `Ungueltiger Anzeigename "${display}". Erlaubt sind Buchstaben, Ziffern und Bindestriche.`,
      );
    }
    return join(this.dir, `${display}.json`);
  }
}
```

```ts
/**
 * Verteilt Stand und Layout an die verbundenen Viewer.
 *
 * Der Stand geht an alle, das Layout nur an die Viewer derselben Anzeige
 * (?display=beamer). Es werden immer vollstaendige Schnappschuesse gesendet,
 * keine Deltas: Ein Viewer, der sich spaeter verbindet, ist sofort richtig.
 *
 * "editing" sagt allen Viewern einer Anzeige, dass gerade jemand das Layout
 * einrichtet - dann zeigen sie die Scheibe als Linien. Bleibt eine Aenderung
 * aus (Editor-Fenster geschlossen), faellt es nach dem Zeitlimit zurueck.
 */
import { IDLE, type ViewerState } from "./game-state.js";
import type { DisplayLayout } from "./layout.js";

export interface DisplaySocket {
  send(data: string): void;
  on(event: "close", listener: () => void): unknown;
}

export interface LayoutSource {
  read(display: string): DisplayLayout;
  write(display: string, layout: unknown): DisplayLayout;
}

export type ViewerMessage =
  | { type: "state"; state: ViewerState }
  | { type: "layout"; layout: DisplayLayout; editing: boolean };

export const EDIT_TIMEOUT_MS = 60_000;

export class DisplayHub {
  readonly #clients = new Map<DisplaySocket, string>();
  readonly #editing = new Map<string, NodeJS.Timeout>();
  #state: ViewerState = IDLE;

  constructor(
    private readonly layouts: LayoutSource,
    private readonly editTimeoutMs = EDIT_TIMEOUT_MS,
  ) {}

  attach(socket: DisplaySocket, display: string): void {
    this.#clients.set(socket, display);
    socket.on("close", () => this.#clients.delete(socket));
    this.#send(socket, { type: "state", state: this.#state });
    this.#send(socket, {
      type: "layout",
      layout: this.layouts.read(display),
      editing: this.isEditing(display),
    });
  }

  /** Setzt den Stand und schiebt ihn an alle Viewer. */
  broadcast(state: ViewerState): void {
    this.#state = state;
    for (const socket of [...this.#clients.keys()]) this.#send(socket, { type: "state", state });
  }

  /** Prueft und speichert das Layout und schickt es an alle Viewer dieser Anzeige. */
  updateLayout(display: string, layout: unknown, editing: boolean): DisplayLayout {
    const saved = this.layouts.write(display, layout);
    this.#setEditing(display, editing);
    this.#publishLayout(display, saved);
    return saved;
  }

  isEditing(display: string): boolean {
    return this.#editing.has(display);
  }

  close(): void {
    for (const timer of this.#editing.values()) clearTimeout(timer);
    this.#editing.clear();
  }

  get state(): ViewerState {
    return this.#state;
  }

  get clientCount(): number {
    return this.#clients.size;
  }

  #setEditing(display: string, editing: boolean): void {
    clearTimeout(this.#editing.get(display));
    this.#editing.delete(display);
    if (!editing) return;
    const timer = setTimeout(() => {
      this.#editing.delete(display);
      this.#publishLayout(display, this.layouts.read(display));
    }, this.editTimeoutMs);
    timer.unref?.();
    this.#editing.set(display, timer);
  }

  #publishLayout(display: string, layout: DisplayLayout): void {
    const message: ViewerMessage = { type: "layout", layout, editing: this.isEditing(display) };
    for (const [socket, name] of [...this.#clients]) {
      if (name === display) this.#send(socket, message);
    }
  }

  #send(socket: DisplaySocket, message: ViewerMessage): void {
    try {
      socket.send(JSON.stringify(message));
    } catch {
      this.#clients.delete(socket);
    }
  }
}
```

```js
/*
 * Geometrie der Scheibe in Millimetern um den Mittelpunkt.
 *
 * Offizielle Turniermasse, weil der Viewer auf eine echte Scheibe projiziert:
 * das Licht soll auf den echten Draehten liegen. SVG-Richtung: x nach rechts,
 * y nach unten; Winkel im Uhrzeigersinn ab oben (die 20).
 *
 * Reine Funktionen ohne DOM - mit Vitest getestet.
 */

export const RADIUS = {
  bull: 6.35,
  outerBull: 15.9,
  tripleInner: 99,
  tripleOuter: 107,
  doubleInner: 162,
  doubleOuter: 170,
  board: 225,
};

export const NUMBERS = [20, 1, 18, 4, 13, 6, 10, 15, 2, 17, 3, 19, 7, 16, 8, 11, 14, 9, 12, 5];
export const SEGMENT_DEG = 18;

const MISS = { multiplier: 0, number: 0, ring: null };
const round = (n) => Number(n.toFixed(3));

/** Autodarts-Koordinaten (1 = Aussenkante Double, y nach oben) → mm. */
export function coordsToPoint(coords) {
  return { x: coords.x * RADIUS.doubleOuter, y: -coords.y * RADIUS.doubleOuter };
}

export function pointAt(radius, angleDeg) {
  const rad = (angleDeg * Math.PI) / 180;
  return { x: radius * Math.sin(rad), y: -radius * Math.cos(rad) };
}

function angleOf(point) {
  return ((Math.atan2(point.x, -point.y) * 180) / Math.PI + 360) % 360;
}

export function fieldAt(point) {
  const r = Math.hypot(point.x, point.y);
  if (r <= RADIUS.bull) return { multiplier: 2, number: 25, ring: null };
  if (r <= RADIUS.outerBull) return { multiplier: 1, number: 25, ring: null };
  if (r > RADIUS.doubleOuter) return { ...MISS };
  const index = Math.floor(((angleOf(point) + SEGMENT_DEG / 2) % 360) / SEGMENT_DEG);
  const number = NUMBERS[index];
  if (r > RADIUS.doubleInner) return { multiplier: 2, number, ring: null };
  if (r > RADIUS.tripleOuter) return { multiplier: 1, number, ring: "outer" };
  if (r > RADIUS.tripleInner) return { multiplier: 3, number, ring: null };
  return { multiplier: 1, number, ring: "inner" };
}

/** Radien [innen, aussen] der Flaechen eines Feldes; Single ohne Teil = beide Teile. */
function bands(field) {
  if (field.number === 25) {
    return field.multiplier === 2 ? [[0, RADIUS.bull]] : [[RADIUS.bull, RADIUS.outerBull]];
  }
  if (field.multiplier === 3) return [[RADIUS.tripleInner, RADIUS.tripleOuter]];
  if (field.multiplier === 2) return [[RADIUS.doubleInner, RADIUS.doubleOuter]];
  const inner = [RADIUS.outerBull, RADIUS.tripleInner];
  const outer = [RADIUS.tripleOuter, RADIUS.doubleInner];
  if (field.ring === "inner") return [inner];
  if (field.ring === "outer") return [outer];
  return [inner, outer];
}

function isField(field) {
  return field.multiplier !== 0 && (field.number === 25 || NUMBERS.includes(field.number));
}

/** Vollkreis bzw. Ring; mit fill-rule="evenodd" zeichnen. */
function ringPath(r1, r2) {
  const circle = (r, sweep) =>
    `M 0 ${round(-r)} A ${r} ${r} 0 1 ${sweep} 0 ${round(r)} A ${r} ${r} 0 1 ${sweep} 0 ${round(-r)} Z`;
  return r1 === 0 ? circle(r2, 1) : `${circle(r2, 1)} ${circle(r1, 0)}`;
}

function sectorPath(r1, r2, a1, a2) {
  const p1 = pointAt(r2, a1);
  const p2 = pointAt(r2, a2);
  const p3 = pointAt(r1, a2);
  const p4 = pointAt(r1, a1);
  return (
    `M ${round(p1.x)} ${round(p1.y)} A ${r2} ${r2} 0 0 1 ${round(p2.x)} ${round(p2.y)} ` +
    `L ${round(p3.x)} ${round(p3.y)} A ${r1} ${r1} 0 0 0 ${round(p4.x)} ${round(p4.y)} Z`
  );
}

export function fieldPath(field) {
  if (!isField(field)) return "";
  if (field.number === 25) {
    const [[r1, r2]] = bands(field);
    return ringPath(r1, r2);
  }
  const center = NUMBERS.indexOf(field.number) * SEGMENT_DEG;
  return bands(field)
    .map(([r1, r2]) => sectorPath(r1, r2, center - SEGMENT_DEG / 2, center + SEGMENT_DEG / 2))
    .join(" ");
}

/** Mitte eines Feldes - fuer Darts, die Autodarts ohne Koordinaten meldet. */
export function fieldCenter(field) {
  if (!isField(field)) return null;
  if (field.number === 25) {
    return field.multiplier === 2 ? { x: 0, y: 0 } : pointAt((RADIUS.bull + RADIUS.outerBull) / 2, 0);
  }
  const [r1, r2] = bands(field).at(-1);
  return pointAt((r1 + r2) / 2, NUMBERS.indexOf(field.number) * SEGMENT_DEG);
}
```

```js
/*
 * Beschriftungen wie in der Autodarts-Spielansicht. Reine Funktionen ohne DOM.
 */

const PREFIX = ["", "S", "D", "T"];
const MODE_LETTER = { Straight: "S", Double: "D", Master: "M" };

export function fieldLabel(field) {
  if (field.multiplier === 0 || field.number === 0) return "MISS";
  if (field.number === 25) return field.multiplier === 2 ? "BULL" : "25";
  return `${PREFIX[field.multiplier]}${field.number}`;
}

/** Eine Nachkommastelle, Punkt als Trenner - so schreibt es Autodarts. */
export function formatAverage(value) {
  return (Number.isFinite(value) ? value : 0).toFixed(1);
}

/** Die Chips oben links: Startpunkte, Ziel, Ein-/Ausstieg. */
export function matchChips(match) {
  const target = match.setsToWin
    ? `Erster bis ${match.setsToWin} ${match.setsToWin === 1 ? "Set" : "Sets"}`
    : `Erster bis ${match.legsToWin} ${match.legsToWin === 1 ? "Leg" : "Legs"}`;
  const inLetter = MODE_LETTER[match.inMode] ?? "S";
  const outLetter = MODE_LETTER[match.outMode] ?? "S";
  return [String(match.baseScore), target, `${inLetter}I-${outLetter}O`];
}
```

```js
/*
 * Wendet ein Layout auf die Bloecke an. Positionen in Prozent der Flaeche,
 * Groessen in vh - wie im Layout gespeichert.
 */

/** Die SVG der Scheibe reicht bis zum Zahlenring (225 mm), das Layout misst den Double-Ring (170 mm). */
export const BOARD_PER_DOUBLE = 225 / 170;

export function applyLayout(viewer, layout) {
  for (const el of viewer.querySelectorAll(".block[data-block]")) {
    const id = el.dataset.block;
    if (id === "scheibe") {
      const { cx, cy, diameter, rotation } = layout.board;
      const size = diameter * BOARD_PER_DOUBLE;
      el.style.left = `${cx}%`;
      el.style.top = `${cy}%`;
      el.style.width = `${size}vh`;
      el.style.height = `${size}vh`;
      el.style.transform = `translate(-50%, -50%) rotate(${rotation}deg)`;
      continue;
    }
    const block = layout.blocks[id];
    if (!block) continue;
    el.style.left = `${block.x}%`;
    el.style.top = `${block.y}%`;
    el.style.transform = `scale(${block.scale})`;
  }
}
```

```js
/*
 * Die Scheibe als SVG in Millimetern.
 *
 * Felder, Zahlen und Draehte werden einmal gezeichnet; welche Ebene sichtbar
 * ist, entscheidet data-mode an der SVG (light, drawn, lines) per CSS. Darts
 * und Hervorhebungen werden bei jedem Stand neu gesetzt.
 */
import {
  NUMBERS,
  RADIUS,
  SEGMENT_DEG,
  coordsToPoint,
  fieldCenter,
  fieldPath,
  pointAt,
} from "./geometry.js";

const SVG = "http://www.w3.org/2000/svg";
const DART_RADIUS = 2.25; // wie Autodarts: 5 von 377,78 Einheiten bis zum Double

function el(name, attrs = {}) {
  const node = document.createElementNS(SVG, name);
  for (const [key, value] of Object.entries(attrs)) node.setAttribute(key, String(value));
  return node;
}

function drawFields(group) {
  group.append(el("circle", { r: RADIUS.board, class: "field-surround" }));
  NUMBERS.forEach((number, index) => {
    const dark = index % 2 === 0; // die 20 ist schwarz mit roten Ringen
    const single = dark ? "field-dark" : "field-light";
    const ring = dark ? "field-red" : "field-green";
    for (const [multiplier, part, cls] of [
      [1, "inner", single],
      [1, "outer", single],
      [3, null, ring],
      [2, null, ring],
    ]) {
      group.append(el("path", { d: fieldPath({ multiplier, number, ring: part }), class: cls }));
    }
  });
  group.append(
    el("path", {
      d: fieldPath({ multiplier: 1, number: 25, ring: null }),
      class: "field-green",
      "fill-rule": "evenodd",
    }),
  );
  group.append(el("path", { d: fieldPath({ multiplier: 2, number: 25, ring: null }), class: "field-red" }));
}

function drawNumbers(group) {
  const radius = (RADIUS.doubleOuter + RADIUS.board) / 2;
  NUMBERS.forEach((number, index) => {
    const angle = index * SEGMENT_DEG;
    const { x, y } = pointAt(radius, angle);
    // Unten stehende Zahlen nicht auf den Kopf stellen.
    const turn = angle > 90 && angle < 270 ? angle - 180 : angle;
    const text = el("text", {
      x: x.toFixed(2),
      y: y.toFixed(2),
      class: "board-number",
      "text-anchor": "middle",
      "dominant-baseline": "central",
      transform: `rotate(${turn} ${x.toFixed(2)} ${y.toFixed(2)})`,
    });
    text.textContent = String(number);
    group.append(text);
  });
}

function drawWires(group) {
  for (const radius of [
    RADIUS.bull,
    RADIUS.outerBull,
    RADIUS.tripleInner,
    RADIUS.tripleOuter,
    RADIUS.doubleInner,
    RADIUS.doubleOuter,
  ]) {
    group.append(el("circle", { r: radius }));
  }
  NUMBERS.forEach((_, index) => {
    const angle = index * SEGMENT_DEG + SEGMENT_DEG / 2;
    const from = pointAt(RADIUS.outerBull, angle);
    const to = pointAt(RADIUS.doubleOuter, angle);
    group.append(el("line", { x1: from.x.toFixed(2), y1: from.y.toFixed(2), x2: to.x.toFixed(2), y2: to.y.toFixed(2) }));
  });
}

function dartMarker(dart) {
  const point = dart.coords ? coordsToPoint(dart.coords) : fieldCenter(dart.field);
  if (!point) return null; // daneben ohne Koordinaten
  return el("circle", { cx: point.x.toFixed(2), cy: point.y.toFixed(2), r: DART_RADIUS, class: "dart" });
}

export function createBoard(svg) {
  svg.setAttribute("viewBox", `${-RADIUS.board} ${-RADIUS.board} ${2 * RADIUS.board} ${2 * RADIUS.board}`);
  const fields = el("g", { class: "board-fields" });
  const numbers = el("g", { class: "board-numbers" });
  const wires = el("g", { class: "board-wires" });
  const highlights = el("g", { class: "board-highlights" });
  const darts = el("g", { class: "board-darts" });
  drawFields(fields);
  drawNumbers(numbers);
  drawWires(wires);
  svg.append(fields, numbers, wires, highlights, darts);

  return {
    render(state) {
      const playing = state.phase === "playing";
      highlights.replaceChildren(
        ...(playing ? state.highlights : []).map((highlight) =>
          el("path", {
            d: fieldPath(highlight.field),
            class: `highlight highlight-${highlight.kind}`,
            "fill-rule": "evenodd",
          }),
        ),
      );
      darts.replaceChildren(...(playing ? state.turn.darts : []).map(dartMarker).filter(Boolean));
    },
  };
}
```

```js
/*
 * Viewer: verbindet sich mit dem Pi und zeichnet, was er schickt.
 *
 * Spielregeln kennt der Viewer nicht - Rest, Bust, Checkout und Sieger kommen
 * fertig vom Pi. Hier wird nur entschieden, wie es aussieht.
 */
import { createBoard } from "./board.js";
import { applyLayout } from "./layout-view.js";
import { SAMPLE_STATE } from "./sample-state.js";

const viewer = document.getElementById("viewer");
const boardSvg = document.getElementById("board-svg");
const messageEl = document.getElementById("message");

/* Mehrere Anzeigen, getrennte Layouts: ?display=beamer, ?display=tv ... */
const display = new URLSearchParams(location.search).get("display") || "standard";
const board = createBoard(boardSvg);

let state = { phase: "idle" };
let layout = null;
let remoteEditing = false;

/* Beim Einrichten ohne laufendes Spiel gaebe es sonst nichts zu platzieren. */
function shownState() {
  return remoteEditing && state.phase !== "playing" ? SAMPLE_STATE : state;
}

function render() {
  const shown = shownState();
  viewer.dataset.phase = shown.phase;
  viewer.classList.toggle("is-remote-editing", remoteEditing);
  messageEl.textContent =
    shown.phase === "idle"
      ? "Warte auf ein Spiel"
      : shown.phase === "unsupported"
        ? `${shown.variant} wird noch nicht unterstützt`
        : "";
  boardSvg.dataset.mode = remoteEditing ? "lines" : (layout?.boardMode ?? "light");
  board.render(shown);
}

function onMessage(message) {
  if (message.type === "state") state = message.state;
  if (message.type === "layout") {
    remoteEditing = message.editing;
    layout = message.layout;
    applyLayout(viewer, layout);
  }
  render();
}

/* --- Verbindung mit automatischem Wiederaufbau --------------------------- */

let retryDelay = 500;

function connect() {
  const socket = new WebSocket(`ws://${location.host}/ws?display=${encodeURIComponent(display)}`);

  socket.addEventListener("open", () => {
    retryDelay = 500;
    viewer.classList.remove("is-offline");
  });

  socket.addEventListener("message", (event) => {
    try {
      onMessage(JSON.parse(event.data));
    } catch (error) {
      console.error("Ungueltige Nachricht vom Pi", error);
    }
  });

  // Der letzte Stand bleibt stehen; nur ein kleiner Hinweis in der Ecke.
  socket.addEventListener("close", () => {
    viewer.classList.add("is-offline");
    setTimeout(connect, retryDelay);
    retryDelay = Math.min(retryDelay * 2, 10000);
  });
}

render();
connect();
```

```js
/*
 * Kopf, Aufnahmeleiste und Spielerkarten im Stil der Autodarts-Spielansicht.
 *
 * Die Karten werden je Platz einmal aufgebaut und danach nur aktualisiert:
 * Bilder bei jedem Wurf neu zu setzen liesse sie kurz aufblitzen - auf der
 * Wand sieht man das.
 */
import { fieldLabel, formatAverage, matchChips } from "./labels.js";

/** Autodarts-Standardbild fuer Spieler ohne eigenes Profilbild. Der Dateiname
 *  enthaelt eine Build-Kennung von Autodarts und kann sich mit einer neuen
 *  Autodarts-Version aendern - dann bleibt der Platz leer. */
export const DEFAULT_AVATAR_URL = "https://play.autodarts.com/assets/player-silhouette-X1nJGQO_.png";

const flagUrl = (country) =>
  `https://play.autodarts.com/flags/4x3/${encodeURIComponent(country)}.svg`;

function node(tag, className, text) {
  const el = document.createElement(tag);
  if (className) el.className = className;
  if (text !== undefined) el.textContent = text;
  return el;
}

function dartIcon() {
  const svg = document.createElementNS("http://www.w3.org/2000/svg", "svg");
  svg.setAttribute("class", "dart-icon");
  svg.setAttribute("viewBox", "0 0 100 24");
  const use = document.createElementNS("http://www.w3.org/2000/svg", "use");
  use.setAttribute("href", "#dart-icon");
  svg.append(use);
  return svg;
}

export function renderHead(el, match) {
  el.replaceChildren(...matchChips(match).map((text) => node("span", "chip", text)));
}

export function renderTurn(bar, turn) {
  bar.classList.toggle("is-busted", turn.busted);
  const slots = [0, 1, 2].map((index) => {
    const dart = turn.darts[index];
    const slot = node("span", "turn-dart");
    if (dart) slot.textContent = fieldLabel(dart.field);
    else slot.append(dartIcon());
    return slot;
  });
  bar.replaceChildren(...slots, node("span", "turn-total", turn.busted ? "BUST" : String(turn.points)));
}

/* --- Spielerkarten -------------------------------------------------------- */

/** Setzt ein Bild nur, wenn sich die Quelle aendert - sonst kein Neuladen. */
function setImage(img, url) {
  if (img.dataset.url === url) return;
  img.dataset.url = url;
  img.dataset.fallback = "";
  img.style.visibility = "";
  img.src = url;
}

function buildCard() {
  const card = node("article", "card");

  const head = node("header", "card-head");
  const avatar = node("img", "card-avatar");
  avatar.alt = "";
  // Eigenes Bild kaputt → Autodarts-Standardbild; auch das kaputt → leer.
  avatar.addEventListener("error", () => {
    if (avatar.dataset.fallback !== "1" && avatar.dataset.url !== DEFAULT_AVATAR_URL) {
      avatar.dataset.fallback = "1";
      avatar.src = DEFAULT_AVATAR_URL;
    } else {
      avatar.style.visibility = "hidden";
    }
  });
  const name = node("span", "card-name");
  const flag = node("img", "card-flag");
  flag.alt = "";
  flag.addEventListener("error", () => {
    flag.style.visibility = "hidden";
  });
  head.append(avatar, name, flag);

  const main = node("div", "card-main");
  const checkout = node("ol", "card-checkout");
  const score = node("span", "card-score");
  const legs = node("span", "card-legs");
  main.append(checkout, score, legs);

  const averages = node("p", "card-averages");
  const darts = node("p", "card-darts");
  const dartsCount = node("b");
  darts.append(dartIcon(), dartsCount);

  card.append(head, main, averages, darts);
  return { card, avatar, name, flag, checkout, score, legs, averages, dartsCount };
}

function updateCard(parts, player) {
  parts.card.classList.toggle("is-winner", player.isWinner);
  parts.card.classList.toggle("is-busted", player.busted && !player.isWinner);
  parts.card.classList.toggle("is-active", player.isActive && !player.isWinner && !player.busted);

  setImage(parts.avatar, player.avatarUrl ?? DEFAULT_AVATAR_URL);
  parts.name.textContent = player.name;
  parts.flag.hidden = !player.country;
  if (player.country) setImage(parts.flag, flagUrl(player.country));

  parts.checkout.replaceChildren(
    ...(player.checkout ?? []).map((field) => node("li", "", fieldLabel(field))),
  );
  parts.score.textContent = String(player.score);
  parts.legs.textContent = String(player.legs);
  parts.averages.replaceChildren(
    "Leg ",
    node("b", "", formatAverage(player.average.leg)),
    " / Match ",
    node("b", "", formatAverage(player.average.match)),
  );
  parts.dartsCount.textContent = String(player.dartsThrown);
}

const cards = new WeakMap();

/** slots: die sechs Bloecke spieler-1 … spieler-6; ueberzaehlige werden versteckt. */
export function renderPlayers(slots, players) {
  slots.forEach((slot, index) => {
    const player = players[index];
    slot.hidden = !player;
    if (!player) return;
    let parts = cards.get(slot);
    if (!parts) {
      parts = buildCard();
      cards.set(slot, parts);
      slot.prepend(parts.card);
    }
    updateCard(parts, player);
  });
}
```

`server/public/js/editor.js`:

```js
/*
 * Bearbeiten-Modus: Scheibe und Bloecke verschieben, skalieren, drehen.
 *
 * Jede Aenderung gilt sofort im eigenen Bild und geht gedrosselt an den Pi,
 * der sie an alle Viewer mit demselben Anzeigenamen weiterreicht - so folgt
 * der Beamer live, waehrend man am Laptop zieht. Ausgelegt auf Maus und
 * Tastatur.
 */

const SEND_INTERVAL_MS = 100;
/* Der Pi beendet "editing" nach 60 s ohne Aenderung; solange der Editor offen
   ist, haelt ein Lebenszeichen es an. */
const KEEPALIVE_MS = 30_000;
const BUTTON_HIDE_MS = 3000;

const clamp = (value, min, max) => Math.min(max, Math.max(min, value));
const normalizeAngle = (deg) => ((((deg + 180) % 360) + 360) % 360) - 180;
const distance = (x, y, p) => Math.hypot(x - p.x, y - p.y);
const angle = (x, y, p) => (Math.atan2(y - p.y, x - p.x) * 180) / Math.PI;

const PLUS_KEYS = ["+", "*", "="];
const MINUS_KEYS = ["-", "_"];

/** Aenderung durch Ziehen an einem Block oder Griff. */
function drag(layout, id, handle, start, move, anchor) {
  const dx = ((move.clientX - start.x) / window.innerWidth) * 100;
  const dy = ((move.clientY - start.y) / window.innerHeight) * 100;
  const ratio = distance(move.clientX, move.clientY, anchor) / Math.max(1, distance(start.x, start.y, anchor));

  if (id === "scheibe") {
    const from = start.layout.board;
    const board = layout.board;
    if (handle === "move") {
      board.cx = clamp(from.cx + dx, 0, 100);
      board.cy = clamp(from.cy + dy, 0, 100);
    } else if (handle === "resize") {
      board.diameter = clamp(from.diameter * ratio, 5, 400);
    } else if (handle === "rotate") {
      const turned = angle(move.clientX, move.clientY, anchor) - angle(start.x, start.y, anchor);
      board.rotation = normalizeAngle(from.rotation + turned);
    }
    return;
  }

  const from = start.layout.blocks[id];
  const block = layout.blocks[id];
  if (handle === "move") {
    block.x = clamp(from.x + dx, 0, 100);
    block.y = clamp(from.y + dy, 0, 100);
  } else if (handle === "resize") {
    block.scale = clamp(from.scale * ratio, 0.2, 4);
  }
}

/** Feinschritte per Tastatur; null, wenn die Taste nichts bedeutet. */
function keyAction(event, selected) {
  const step = event.shiftKey ? 1 : 0.1;
  const offset = {
    ArrowLeft: [-step, 0],
    ArrowRight: [step, 0],
    ArrowUp: [0, -step],
    ArrowDown: [0, step],
  }[event.key];
  if (offset) {
    return (layout) => {
      if (selected === "scheibe") {
        layout.board.cx = clamp(layout.board.cx + offset[0], 0, 100);
        layout.board.cy = clamp(layout.board.cy + offset[1], 0, 100);
      } else {
        const block = layout.blocks[selected];
        block.x = clamp(block.x + offset[0], 0, 100);
        block.y = clamp(block.y + offset[1], 0, 100);
      }
    };
  }

  const grow =
    PLUS_KEYS.includes(event.key) || event.code === "NumpadAdd"
      ? 1
      : MINUS_KEYS.includes(event.key) || event.code === "NumpadSubtract"
        ? -1
        : 0;
  if (grow) {
    return (layout) => {
      if (selected === "scheibe") {
        layout.board.diameter = clamp(layout.board.diameter + grow * step, 5, 400);
      } else {
        const block = layout.blocks[selected];
        block.scale = clamp(block.scale + (grow * step) / 10, 0.2, 4);
      }
    };
  }

  const turn = event.code === "KeyQ" ? -1 : event.code === "KeyE" ? 1 : 0;
  if (turn && selected === "scheibe") {
    return (layout) => {
      layout.board.rotation = normalizeAngle(layout.board.rotation + turn * step);
    };
  }
  return null;
}

export function createEditor({ viewer, display, getLayout, applyLocal, onEditingChange }) {
  const button = viewer.querySelector("#edit-toggle");
  const toolbar = viewer.querySelector("#edit-toolbar");
  let editing = false;
  let selected = "scheibe";
  let lastSent = 0;
  let sendTimer = null;
  let keepalive = null;
  let hideTimer = null;

  function send() {
    clearTimeout(sendTimer);
    sendTimer = null;
    lastSent = Date.now();
    fetch(`/api/layout/${encodeURIComponent(display)}`, {
      method: "PUT",
      headers: { "Content-Type": "application/json", "X-Raspdarts": "1" },
      body: JSON.stringify({ layout: getLayout(), editing }),
    }).catch((error) => console.error("Layout konnte nicht gespeichert werden", error));
  }

  /* Hoechstens alle 100 ms; die letzte Aenderung geht immer noch raus. */
  function sendSoon() {
    if (sendTimer) return;
    sendTimer = setTimeout(send, Math.max(0, SEND_INTERVAL_MS - (Date.now() - lastSent)));
  }

  function change(mutate) {
    const layout = structuredClone(getLayout());
    mutate(layout);
    applyLocal(layout);
    refresh();
    sendSoon();
  }

  function select(id) {
    selected = id;
    for (const block of viewer.querySelectorAll(".block[data-block]")) {
      block.classList.toggle("is-selected", block.dataset.block === id);
    }
  }

  function refresh() {
    const mode = getLayout()?.boardMode;
    for (const modeButton of toolbar.querySelectorAll("[data-mode]")) {
      modeButton.setAttribute("aria-pressed", String(modeButton.dataset.mode === mode));
    }
  }

  function setEditing(next) {
    if (!getLayout()) return; // noch kein Layout vom Pi
    editing = next;
    viewer.classList.toggle("is-editing", editing);
    clearInterval(keepalive);
    if (editing) {
      keepalive = setInterval(send, KEEPALIVE_MS);
      select(selected);
    }
    refresh();
    onEditingChange(editing);
    send();
  }

  /* Der Knopf wuerde sonst an die Wand projiziert: nur bei Mausbewegung zeigen. */
  window.addEventListener("pointermove", () => {
    button.classList.add("is-visible");
    clearTimeout(hideTimer);
    hideTimer = setTimeout(() => {
      if (!editing) button.classList.remove("is-visible");
    }, BUTTON_HIDE_MS);
  });

  button.addEventListener("click", () => setEditing(!editing));

  toolbar.addEventListener("click", (event) => {
    const mode = event.target.closest("[data-mode]")?.dataset.mode;
    if (mode) change((layout) => {
      layout.boardMode = mode;
    });
  });

  viewer.addEventListener("pointerdown", (event) => {
    if (!editing || event.button !== 0) return;
    const block = event.target.closest(".block[data-block]");
    if (!block) return;
    event.preventDefault();
    const id = block.dataset.block;
    select(id);

    const handle = event.target.closest("[data-handle]")?.dataset.handle ?? "move";
    const start = { x: event.clientX, y: event.clientY, layout: structuredClone(getLayout()) };
    const rect = block.getBoundingClientRect();
    const anchor =
      id === "scheibe"
        ? { x: rect.left + rect.width / 2, y: rect.top + rect.height / 2 }
        : { x: rect.left, y: rect.top };

    block.setPointerCapture(event.pointerId);
    const onMove = (move) => change((layout) => drag(layout, id, handle, start, move, anchor));
    const onUp = () => {
      block.removeEventListener("pointermove", onMove);
      block.removeEventListener("pointerup", onUp);
      block.removeEventListener("pointercancel", onUp);
      send();
    };
    block.addEventListener("pointermove", onMove);
    block.addEventListener("pointerup", onUp);
    block.addEventListener("pointercancel", onUp);
  });

  viewer.addEventListener(
    "wheel",
    (event) => {
      if (!editing || !event.target.closest('[data-block="scheibe"]')) return;
      event.preventDefault();
      // Mit Umschalt melden manche Browser die Bewegung als deltaX.
      const direction = Math.sign(event.deltaY || event.deltaX);
      const step = event.shiftKey ? 0.1 : 1;
      select("scheibe");
      change((layout) => {
        layout.board.diameter = clamp(layout.board.diameter - direction * step, 5, 400);
      });
    },
    { passive: false },
  );

  window.addEventListener("keydown", (event) => {
    if (!editing) return;
    if (event.key === "Escape") {
      setEditing(false);
      return;
    }
    const action = keyAction(event, selected);
    if (!action) return;
    event.preventDefault();
    change(action);
  });

  return { isEditing: () => editing, refresh };
}
```
